# UgCS-Geotagger

Development and support for UgCS-GeoTagger has ended. All its functionality has been transferred to a new product, SPH Engineering GeoHammer - https://github.com/ugcs/GeoHammer/wiki. Please download and enjoy the new tool!

UgCS-Geotagger is a simple post-processing tool to inject precise coordinates (latitude, longitude, and altitude) into data files for various sensors (magnetometers, GPR. etc.).
